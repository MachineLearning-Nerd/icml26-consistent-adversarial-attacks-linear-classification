# Method

The verifier parses a literal transcription of the left-side variable sets
and right-side expression signatures in Theorem 4.1. It requires every
declared primal order parameter to have a defining equation and compares the
four displayed conjugate updates with Appendix D equation (119).

The negative control applies only the evident appendix-consistent repair:
Appendix (119) supplies the distinct conjugate updates and equations (39)–(40)
receive primal left sides. The checker must accept that repaired structure;
otherwise it is merely rejecting every system.
