# Route 3 — exact compensation mechanism

Definitions (33)–(34) imply, outside zero-probability decision ties,

`E_rob_cns = E_clean + E_bnd_cns`.

The checker evaluates two million correlated-Gaussian cases spanning four
correlations and four positive attack thresholds. It requires the count-level
identity to hold exactly. A mutation that drops originally misclassified
examples must be rejected in every case.

The identity proves the paper's proposed compensation logic: if boundary
error increases while aggregate consistent robust error decreases, clean error
must decrease by more than boundary error increases. It does not supply the
missing trained-model values as a function of `psi`; therefore it is direct
mechanism evidence but not evidence for the directional Figure 5 trend.

Route verdict: **BLOCKED**.
